# Procurement Spend Analysis & Supplier Performance Dashboard

## Overview

Procurement analytics portfolio project focused on spend analysis and supplier performance evaluation using Excel and Power BI.

## Objectives

- Analyze procurement spend by supplier, category, region, and month
- Evaluate supplier performance
- Track purchase order volume and delivery performance
- Identify high-spend areas
- Identify potential savings opportunities

## Tools Used

- Microsoft Excel
- Power BI
- Pivot Tables
- Data Cleaning
- KPI Analysis
- Dashboarding

## Key Analysis

The project evaluates:

- Supplier spend
- Category spend
- Monthly procurement trends
- Purchase order volume
- Supplier ratings
- On-time delivery
- Delay performance
- Savings opportunities

## Dataset

This is a synthetic portfolio dataset created for learning and demonstration purposes.

## Project File

The Excel workbook contains the raw procurement data, analysis sheets, supplier performance analysis, monthly trends, and dashboard.
